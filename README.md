# IRP Reporting Templates

Reusable templates for institutional research reporting, dashboard planning, and stakeholder communication.

This project is designed for public portfolio use with generic examples only.

## Planned Templates

| Template | Purpose |
| --- | --- |
| Executive summary | Summarizes project purpose, findings, value, and decisions needed |
| Technical appendix | Documents data sources, model logic, validation, and caveats |
| Dashboard specification | Defines pages, measures, visuals, slicers, and governance notes |
| Data request brief | Explains why a field is needed and how it supports institutional decisions |
| Weekly update | Supports recurring team standups and project continuity |

## Communication Standard

Good IRP reporting should:

- define the decision being supported
- show the evidence clearly
- document assumptions
- separate analysis from action
- protect student privacy
- avoid unsupported causal or financial claims
